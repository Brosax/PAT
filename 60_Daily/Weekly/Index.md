# 每周工作索引

每周按 ISO 周编号组织，周一开始、周日结束。各周索引包含每日记录入口、按项目归类的事项，以及后来补录或更正的引用。原话只保存在每日日志中。

## 周列表

尚无周记录。收到工作描述后按需创建周索引，按周倒序排列；已知发生日期属于其他周时，也更新对应周的引用。
